Behind the mirrors

Independent infrastructure. Public access.

Keimirror mirrors Linux distributions and open-source repositories from Keiverse's own infrastructure in Gumi, South Korea. It focuses on fast domestic access, official mirror participation, CDN-assisted resilience, and predictable synchronization from real-time updates to daily refreshes.

Gumi-based mirror Runs from Keiverse's private IDC environment in Gumi for Korean and nearby networks.
High-speed access Uses dual 1 Gbps dedicated ISP uplinks with load balancing for stable throughput.
Official mirror coverage Serves official mirrors including Arch Linux Tier 1, Gentoo, Kali, CachyOS, Artix, and OPNsense.
Regular synchronization Repository jobs refresh from real time to 24-hour intervals depending on upstream needs.

Server profile

Mirror 1 and Mirror 2 are separate Gumi-based servers. Both mirrors use a CDN only for DDoS mitigation, with CDN caching disabled so files are served directly from the origin mirrors.

Disclaimer

When an upstream project lists Keimirror as an official mirror, this service is an official distribution endpoint for that project. Keimirror still serves mirrored files as provided by upstream projects and does not change their licenses, release policies, package contents, or security advisories.

The service is operated on a best-effort basis. Synchronization delays, maintenance windows, routing changes, or abusive traffic controls may temporarily affect availability. Always verify critical downloads with the checksums and signatures published by the upstream project.
